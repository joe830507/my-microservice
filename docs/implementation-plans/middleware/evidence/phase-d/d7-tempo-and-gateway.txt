## 2. 經 Gateway 的前台關鍵字搜尋（前端實際呼叫的路徑）

GET /api/v1/products?keyword=Phase&sortBy=price&sortDirection=asc        -> totalElements=4
GET /api/v1/products?keyword=zzzxxqq                                      -> totalElements=0
